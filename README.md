# ✈️ Tour & Travel Management System

A web-based **Tour & Travel Management System** developed using **Java, JSP, Servlets, MySQL, HTML, CSS, and Bootstrap**.

This project provides a simple platform for users to register, log in, book tickets, and interact with the travel management system. It also includes an **Admin Dashboard** for managing the application.

## 🚀 Features

* 👤 User Registration
* 🔐 User Login & Authentication
* 🎫 Ticket Booking
* 🛠️ Admin Dashboard
* 📩 Contact Form
* 🗄️ MySQL Database Integration
* 📱 Responsive User Interface

## 💡 How It Works

1. Users can create an account.
2. Registered users can log in to the system.
3. Users can browse the available travel services.
4. Users can book tickets through the system.
5. The Admin Dashboard provides administrative functionality.
6. User and booking-related information is managed using MySQL.

## 🎯 Project Objective

The main objective of this project is to develop a web-based travel management system that simplifies **user registration, login, ticket booking, and administrative management** through a centralized platform.
